## 🛠️ 技术栈

- **嵌入式开发**：熟练掌握 **STM32 (Cortex-M3)**、STC89C51 单片机开发；熟悉 ADC 采集、1-Wire 协议、传感器驱动及硬件电路/PCB 设计。
- **底层与系统**：熟练掌握 **C/C++ 编程**；熟悉 **Linux 常用命令**及系统配置；具备 **OpenStack 私有云平台**部署与运维经验。
- **界面与应用**：熟练使用 **Qt 框架** 开发跨平台图形界面（含 QSS 样式优化）；熟悉 Vue 3 全家桶、Java Spring Boot 及微信小程序开发。
- **数据库与工具**：熟练使用 **SQLite (嵌入式数据库)**、MySQL、Redis；掌握 Git、Docker、Nginx、Keil5、Proteus 等开发工具。

## 🌟 核心项目展示

### 1. 基于 STM32 的智能家用水质测量系统 (本科毕业设计)

- **项目描述**：设计并实现了一套多参数水质实时监测系统，集成 pH、TDS、浊度及温度传感器，支持本地 OLED 显示及远程监控。
- **技术亮点**：
  - 独立完成从元器件选型、原理图设计到 PCB 绘制与实物调试的全流程。
  - 设计并实现了**分段线性温度补偿算法**，有效解决了环境温度对 pH 及 TDS 测量精度的影响。
  - 通过 ESP8266 驱动 HTTP 请求实现数据同步上传，上传成功率 >95%。

### 2. 基于 Qt 与 SQLite 的嵌入式终端管理系统 (课程设计)

- **项目描述**：模拟交通一卡通嵌入式终端业务，实现开户、注销、多线路动态刷卡扣费及流水查询功能。
- **技术亮点**：
  - 在资金变动核心模块引入 **SQL 事务机制**，确保嵌入式终端在异常断电或故障时的数据一致性。
  - 数据库操作全面采用参数绑定（Binding）方式，从底层防范 SQL 注入风险，安全性高。
  - 通过多线程优化 UI 交互，提升系统响应速度。

### 3. 基于 STC89C51 的高精度数字频率计 (综合实习)

- **项目描述**：基于 51 单片机实现的宽范围信号测量系统，支持 TTL 信号频率及占空比测量。
- **技术亮点**：灵活配置定时器与中断资源，采用计数与定时相结合的自适应算法，频率测量分辨率达 0.1Hz，相对误差控制在 1% 以内。

### 4. 基于 OpenStack 的私有云平台部署与运维

- **项目描述**：在 Ubuntu Linux 环境下完成 Keystone、Neutron、Glance 等核心组件部署。
- **技术亮点**：实现了计算、网络与存储资源的统一管理与调度，掌握了 Linux 系统运维及分布式架构调试方法。
